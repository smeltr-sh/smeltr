# Contributing

Smeltr is not taking code contributions yet, so pull requests are closed without merging.

Issues are welcome: bugs, questions, and what you want Smeltr to do. Open one at
<https://github.com/smeltr-sh/smeltr/issues>. A security problem goes to
[support@smeltr.sh](mailto:support@smeltr.sh) instead, as [SECURITY.md](SECURITY.md) says.
